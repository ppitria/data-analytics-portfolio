# AI-Generated Text Detection for Automated Essay Scoring

This project integrates an AI text detection model with an automated essay scoring system. Its goal is to support the evaluation of student answers while also indicating whether a response was written independently or generated by AI.

## System Overview

The system consists of two main components:

### 1. AI vs. Human Text Detection Model

This model identifies whether a text was written by a human or generated by AI. It is built by fine-tuning **IndoBERT**, allowing it to capture the characteristics of the Indonesian language more accurately.

### 2. Automated Essay Scoring System

This component scores student answers automatically using:

- Text representation based on word embeddings
- Similarity measurement using cosine similarity

This approach allows the system to compare a student's answer against a reference answer in an objective and measurable way. It is designed for exams, assignments, and other essay-based assessments.

## Integration and Workflow

The two components are combined using a rule-based approach that applies an **AI penalty** as a recommended score adjustment. The workflow is as follows:

1. The student's answer is passed through the detection model to estimate the probability that AI was used.
2. In parallel, the same answer is scored by the automated scoring system.
3. A final score is recommended by reducing the automated score according to the detected AI percentage.

This approach is not meant to punish students automatically. Instead, it provides a data-driven recommendation to support the grader's judgment.

## Dataset

The dataset is private and consists of student answers collected across various fields of study. For the AI-labeled data, answers were generated using several popular AI models:

- ChatGPT
- Gemini
- Microsoft Copilot
- DeepSeek
- Claude
- Perplexity
- Meta AI

Using multiple generators exposes the detection model to a diverse range of AI writing styles.
